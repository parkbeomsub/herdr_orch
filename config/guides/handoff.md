# 가이드: 핸드오프 규칙 (전 팀 공통)

리서치로 확인된 5개 팀 유형의 공통 패턴이다. 팀 종류와 무관하게 지킨다.

1. **단일 오너 원칙** — 모든 산출물에는 최종 승인자가 1명이다.
   여러 명이 "괜찮다"고 해도 오너가 승인하지 않으면 완료가 아니다.

2. **명시적 핸드오프** — 자기 산출물을 **누구에게** 넘기는지 항상 알고 있어야 한다.
   완료 보고 시 "다음 수령자"를 함께 적는다. 예: `초고 완료 → 에디터에게 넘김`

3. **사이클 종결자** — 모든 작업은 측정 → 학습 → 재기획으로 닫힌다.
   결과를 내고 끝내지 말고, 무엇이 잘/안 됐는지 한 줄을 남겨 다음 사이클에 넘긴다.

4. **넘기고 끝이 아니다** — 다음 단계에서 문제가 생기면 원 담당자가 함께 본다.
   "내 일은 끝났다"는 금지.

5. **막히면 즉시 알린다** — 혼자 30분 이상 같은 곳에서 막히면 orch에 보고한다.
   추측으로 진행해서 잘못된 산출물을 넘기는 게 가장 비싸다.
