# 가이드: 플랫폼별 운영 규칙 (실측 근거)

출처 등급: **A**=공식발표·소스코드·논문 / **B**=대규모 표본 직접분석 / **C**=마케팅 블로그 재인용
아래 규칙은 A·B에서만 도출했다. 전체 근거는 `research/2026-07-28-platform-growth-strategy.md`.

## 전 플랫폼 공통 제약

1. **같은 텍스트를 두 플랫폼에 붙여넣지 마라.** 훅·구조·CTA를 플랫폼별로 재조립한다.
   Instagram은 재포장이 아니라 **재제작**이다(리포스트 페널티 -60~80%).
2. **모든 문단에 이 테스트를 적용하라: "이 문장이 다른 회사·산업·시점에도 참인가?"**
   참이면 삭제하고 고유 수치나 실제 장애 사례로 교체한다.
   `"it's not X, it's Y"` 구문은 **전 플랫폼 금지어** (LinkedIn이 명시적으로 표적화).
3. **팔로워 수를 1차 KPI로 쓰지 마라.** 1만~10만 구간에서 팔로워당 도달률이
   18~28% → **8~15%로 반토막** 난다. 팔로워가 10배 늘어도 도달은 3~5배만 는다.
   1차 KPI: **저장수 · DM 공유수 · 뉴스레터 구독 · GitHub 스타**.
4. **시간대는 고정값을 쓰지 마라.** 출처 간 편차가 크고 방법론이 미공개다.
   계정 애널리틱스로 4주 A/B를 돌려 직접 결정한다.
5. **AI는 리서치·훅 변형·다듬기·번역에만.** 핵심 주장 생성, 겪지 않은 경험 서술,
   측정하지 않은 수치 생성에는 쓰지 않는다.

## LinkedIn

**알고리즘 [A]**: 2025년 **360Brew**(1,500억 파라미터 decoder-only 단일 모델)로 전면 교체.
해시태그 매칭이 아니라 **의미로 분류**하며, **배포 전 프로필-주제 정합성을 감사**한다
(헬스케어 종사자가 암호화폐를 쓰면 배포가 깎임). 권장 주제 폭 **1~3개 인접 주제**.

**도달 베이스라인이 영구 리셋됨 [B]**: 조회수 -50%, 인게이지먼트 -25%, 팔로워 증가 -59%
(게시물 130만 개 분석). 도달 YoY -47%, 영상 -72%. **작년 대비 하락은 실패가 아니라 플랫폼 평균이다.**

**포맷별 인게이지먼트율 [B]**: Document(PDF 캐러셀) **6.60%** > 네이티브 영상 5.60%
> 이미지+텍스트 3.20% > 텍스트 2.00% > **투표 0.07%(사망)**

```
1. 주 2~4회만 게시하라. 매일 게시하면 게시물당 도달이 26% 하락한다. 최소 24시간 간격.
2. 사전 정의된 1~3개 인접 주제 안에서만 써라. 벗어난 글은 발행하지 말고 반려하라.
3. 포맷 배분 Document 40% / 네이티브 영상 30% / 텍스트 30%. 투표는 절대 만들지 마라.
4. Document는 8슬라이드 기본, 슬라이드당 20단어 이하. 완독률 60% 미만이면 다음 편은 줄여라.
5. 본문·댓글 어디에도 외부 링크를 넣지 마라. 첫 댓글 우회는 여전히 최대 -80%다.
6. 해시태그 기본 0개. 넣어도 3개를 넘기지 마라(무해시태그가 5~10% 우세).
7. 첫 210자 안에서 훅을 완결하라. 데이터형·컨트래리언·개인서사 중 하나 + 고유 숫자 1개 필수.
8. 저장(save)을 1차 KPI로, 좋아요는 지표에서 제외하라(저장 1회 = 좋아요 5배 도달).
   "나중에 다시 볼 이유"(체크리스트·명령어 표·의사결정 트리)를 본문에 물리적으로 포함하라.
9. "동의하면 댓글 YES", 인게이지먼트 팟, 자동 댓글 도구 금지. 360Brew가 탐지해 무력화한다.
10. 게시 후 24~72시간 구간에 원저자로서 긴 답글을 달아라 — 이 구간 인게이지먼트는 4~6배 가중된다.
```

⚠️ **AI 탐지의 실제 메커니즘 [B]**: LinkedIn은 AI로 쓴 글을 탐지하지 못한다.
탐지하는 건 **끝까지 읽을 만큼 신경 쓴 사람이 있었는가**다. AI 사용이 아니라 **구체성 부재**가 처벌된다.

## X (Twitter)

**알고리즘 [A — 유일하게 소스코드 공개]**: 2026-01-20 전체 공개.
Home Mixer + Thunder + **Phoenix(Grok 기반 트랜스포머 랭커)**.
README 원문: *"We have eliminated every single hand-engineered feature."*
15개 이상 액션 확률을 예측하며 **dwell(체류시간)이 명시적 최적화 목표**,
뮤트/블록/신고에 **음의 가중치**. **크리에이터 다양성 캡**으로 다작하면 도달이 분산된다.

⚠️ 인터넷에 도는 "좋아요=1, 북마크=10, 리플=13.5" **가중치 표는 공개 코드에 없다. 미확인.**

**스레드는 기본값이 아니다 [B]**: 동일 주제 A/B에서 **롱폼 단문 7.03% vs 스레드 4.72%**.
이유 — **스레드는 각 트윗이 독립 스코어링**되어 1번이 임계치를 못 넘기면 2~10번은 아무도 못 본다.

```
1. 하루 3~5개만, 최소 2시간 간격. 크리에이터 다양성 캡 때문에 그 이상은 도달을 나눈다.
2. 기본 포맷은 롱폼 단일 게시물이다. 스레드는 순차적 절차 설명에만 쓰고 5~7편을 넘기지 마라.
3. 외부 링크는 본문 금지, 항상 첫 리플에 배치하라.
4. 매일 15~30분을 본인의 2~10배 규모 계정에 리플하는 데 써라. 자기 홍보 금지, 가치만 추가.
   이것이 1만 미만 구간의 주 성장 채널이다.
5. 리플에 구체적 사실이나 반례를 담아라. "great post" 류는 2026-03 다운보트 시스템의 표적이다.
6. 영상은 네이티브 업로드, 2분 20초 미만. YouTube 링크로 대체하지 마라.
7. 첫 30~60분 리플에 전부 답하라. 가시성 점수는 약 6시간마다 절반이 된다.
8. 게시물의 80%를 단일 주제 영역 안에 유지하라(주제 집중 계정은 For You 배포 최대 3배).
9. 매주 최소 1개는 "숫자가 든 실패담"을 올려라 — 장애·비용 폭증·롤백·벤치마크 실패.
10. 링크를 유통할 계획이면 Premium을 유지하라 — 비Premium 링크 게시물은 중앙값 인게이지먼트가 사실상 0이다.
```

## 기술 블로그

**유통 구조가 검색에서 인용으로 바뀜**: 생성형 AI 레퍼럴 19개월간 **9.9배**,
전환율 ChatGPT **15.9%**로 오가닉 검색보다 높다.

**LLM이 인용하는 소스 1~3위 = Reddit · LinkedIn · YouTube [B]**. 개인 블로그가 아니다.
- Reddit 멘션 많은 도메인은 ChatGPT 인용 **3.9배** / Quora 4.1배
- **YouTube 트랜스크립트가 AI 가시성과 상관계수 0.737로 최강 신호**
- **1차 연구(직접 측정) 페이지는 평균 11.3회 인용 vs 비1차 3.4회 = 3.3배**

```
1. 모든 포스트에 직접 측정한 숫자를 최소 1개 포함하라. 남의 숫자만 인용한 글은 발행하지 마라.
2. "AI가 통째로 인용할 수 있는" 요약 표나 직답 문단을 상단에 배치하라. 결론을 끝에 숨기지 마라.
3. 발행 후 Reddit 관련 서브와 LinkedIn에 핵심 주장을 본문으로 게시하라(링크 투척 금지).
4. Medium을 1차 발행처로 쓰지 마라(게시물 약 1/3이 AI 생성). 자체 도메인을 정본으로.
5. llms.txt에 시간 쓰지 마라 — GPTBot도 Google도 읽지 않는다. OSS 문서 사이트라면 예외.
6. 제목과 H2를 실제 검색·질문 문장 그대로 써라. 비유적 제목은 LLM 추출 대상이 못 된다.
7. 벤치마크에는 환경 명세(하드웨어·버전·데이터셋·측정법)를 표로 명시하라.
8. 각 포스트를 YouTube 영상 1개로도 만들어라(상관계수 0.737).
9. 뉴스레터 구독을 유일한 CTA로 고정하라 — 알고리즘 리스크가 없는 유일한 자산이다.
10. 직접 실행하지 않은 명령어, 측정하지 않은 수치, 겪지 않은 장애를 절대 서술하지 마라.
```

## Instagram

**랭킹 신호 [A/B]**: ①총 시청시간+재시청률 ②**sends per reach(DM 공유)** ③likes per reach
④**양방향 대화(2026-03 추가)** ⑤원본성·출처.
**Sends는 좋아요의 3~5배 가중**이며 비팔로워 도달에 결정적.

**⚠️ 계정 규모에 따라 정답이 뒤집힌다 [B]** — 이게 가장 중요하다:

| 계정 규모 | Reels | 캐러셀 |
|---|---|---|
| **<1,000** | **134 views** | 56 views |
| >1M | 110,500 | **217,668** |

**"캐러셀이 인게이지먼트율이 높다"는 조언은 대형 계정 현상이다. 1만 미만에서 따르면 성장이 멈춘다.**

```
1. Reels를 주력으로 주 3~5회. 캐러셀 중심 전략은 100만 이상에서만 유효하다.
2. 신규 도달용 Reels는 30초 미만. 30~90초는 기존 팔로워 대상 교육용에만.
3. 첫 3초에 결론이나 결과 화면을 먼저 보여라(3초 리텐션 60%가 광역 배포 임계치).
   인트로·로고·자기소개를 앞에 두지 마라.
4. 다른 플랫폼 영상 파일을 그대로 올리지 마라. 워터마크는 즉시 디모션,
   30일 내 리포스트 10개면 추천에서 완전 제외된다. Instagram용으로 다시 만들어라.
5. 1차 KPI는 sends per reach다. "동료에게 보내주세요"를 캡션이 아니라 영상 마지막 화면에 넣어라.
6. 해시태그 30개 금지(2024-12 해시태그 팔로우 기능 삭제됨). 캡션 첫 문장과 프로필에 키워드를 자연어로.
7. 매일 스토리 3~7 프레임 + 질문 스티커·DM 유도 하나(2026-03부터 양방향 대화가 랭킹 신호).
8. 스톡 이미지·템플릿 인포그래픽 금지. 터미널 녹화·실제 대시보드·before/after 비용 화면을 써라.
9. 게시물을 연달아 올리지 마라 — Instagram이 일부를 숨긴다.
10. 주제를 좁게 고정하라. 사용자가 "Your Algorithm" 대시보드에서 토픽을 직접 제거할 수 있다.
```

⚠️ Instagram은 5개 채널 중 **개발자 청중과 가장 먼 채널**이다.
역할을 "AI·인프라를 **비개발자 의사결정자**에게 설명하는 창구"로 좁게 잡아라.
코드가 아니라 **"이게 왜 비용을 줄이는가"**를 다뤄라.

## GitHub

**Trending은 절대 스타 수가 아니라 star velocity** — 해당 레포의 자체 과거 평균 대비 증가율.
평소 2 stars/day인 레포가 10을 받으면, 평소 50인 레포가 60을 받는 것보다 높다.
**"하루 80 스타가 몇 주에 걸친 꾸준한 유입보다 높게 랭크된다."**

```
1. 홍보를 여러 주에 분산하지 마라. HN(화~목 08–10 ET)·Reddit·X·LinkedIn·뉴스레터를 같은 날 터뜨려라.
2. README 첫 두 줄에 "이것이 무엇이고 왜 필요한가"를 끝내라 — 15초 안에 스타 결정이 난다.
3. 스크롤 없이 보이는 위치에 15~30초·5MB 이하 데모 GIF를 넣어라. 텍스트만인 README는 발행 금지.
4. README는 500~1,500 단어. 기능은 불릿이 아니라 표로("표는 스캔되고 불릿은 안 된다").
5. 배지는 정확히 4개: Stars, License, Build, Last commit. 다운로드 수·커버리지 금지.
6. 복붙하면 첫 시도에 되는 Quick Start를 넣어라. 사전 설정이 필요하면 그 자체가 버그다.
7. 런치 전에 벤치마크나 블로그 포스트를 먼저 발행하라 — 스타를 요청하기 전에 개발자를 끌어와라.
8. CONTRIBUTING.md + good first issue 라벨 5개 이상. 이슈·PR에 24시간 내 응답하라.
9. 런치 후 Insights→Traffic으로 레퍼러를 기록하고 star-history.com으로 채널별 상관을 분석해,
   "노력 시간당 스타"가 낮은 채널을 다음 런치에서 버려라.
10. 스타를 사거나 교환하지 마라. star-history 곡선에서 즉시 드러나며 개발자 청중에선 회복 불가다.
```

## AI 콘텐츠 포화도 — 우리가 왜 이길 수 있는가 [B]

Pangram 2026-04, 게시물 100만+ 스캔:

| 플랫폼 | AI 완전 생성 |
|---|---|
| LinkedIn 롱폼(250단어+) | **41%** |
| Medium | 약 33% |
| X | 25% |
| Reddit 게시물 | 11.6% |
| **Reddit 댓글** | **1.9%** |

**Reddit 댓글은 인터넷에서 남아 있는 가장 인간적인 공간이자 LLM 인용 1위 소스다.**
그리고 기술 커뮤니티는 아직 오염되지 않았기 때문에 **AI 티가 나면 즉시 식별된다** —
여기서 발각되는 건 도달 하락이 아니라 **평판 소멸**이다.

⚠️ van der Blom: *"내 게시물의 첫 5분 댓글 중 80%가 AI가 쓴 것."*
**AI 댓글 자동화는 이미 무의미하다.**
